# Sistema de Cadastro de Funcionários

## Sobre o projeto

Sistema desenvolvido para realizar o cadastro e gerenciamento de funcionários.

O projeto foi desenvolvido como atividade acadêmica, com foco na aplicação de conceitos de desenvolvimento de sistemas.

## Funcionalidades

* Cadastro de funcionários
* Consulta de funcionários
* Edição de dados
* Exclusão de funcionários

## Tecnologias

* HTML
* CSS
* JavaScript
